# My-block-data
This wordpress plugin can be used to import specially structured text.

The data processed by the plugin shall have the following structure:
(YYYY/MM/DD) Caption
URL1
URL2
URL...
URL N

A single block like this is allowed to have one until N URLs.

For example the data could be:
```
(2025/01/10) Heading
https://newspaper1.com/article1
https://newspaper2.org/article1
```
